# Whiteguard Security Platform
> **Project Status: Archived / Legacy**  
> This repository serves as the historical documentation for the Whiteguard startup initiative. 

Whiteguard was conceptualized and developed as a comprehensive application security and DevSecOps platform. The initiative aimed to bridge the gap between software development and security by automating vulnerability assessments, integrating static and dynamic application security testing (SAST/DAST), and streamlining pipeline automation.

## Recognition

In **May 2025**, the Whiteguard business plan and technical prototype were awarded **3rd Place at the Ideathon in Ioannina**, an event organized in collaboration with the **Piraeus Startup Accelerator** and **POS4work**.

## Technical Scope
While the project is no longer actively maintained for commercial deployment, the core technical foundations explored several advanced domains:
* **DevSecOps Automation:** Pipeline integrations utilizing tools like Semgrep and OWASP ZAP.
* **Security Mechanics:** Implementation of pre-commit hooks, API security protocols, and strict access controls.
* **Modern Web Technologies:** Leveraging component-based UI frameworks and utility-driven styling (such as React and Tailwind CSS) for rapid prototyping and deployment.
